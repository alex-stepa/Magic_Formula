## Purpose

Terrain is an abstraction, not a concrete ground: the solver only ever asks for surface
height and normal at a point, so flat ground, procedural hills and a real SRTM heightfield
are interchangeable (`src/world.rs`). Rapier colliders exist for the static world only
(`src/physics.rs`).

## Requirements

### Requirement: Terrain sits behind the `World` trait

Every terrain implementation MUST expose `height(x, z) -> f32` and `normal(x, z) -> Vec3` in
world coordinates with Y up. `normal` MUST have a default implementation using central
differences over `height`, so a new terrain only has to implement height; an analytic normal
is provided only when it is cheap.

#### Scenario: New terrain implementation

- **WHEN** a new terrain type implements `World` with `height` only
- **THEN** it is usable everywhere a `World` is expected
- **AND** its normals come from the trait's finite-difference default

#### Scenario: Solver queries the ground

- **WHEN** the solver resolves wheel or node contact with the ground
- **THEN** it reads height and normal through the `Terrain` resource's trait object,
  never a concrete terrain type

### Requirement: Selectable maps

The game MUST offer terrain choice through `MapKind` (`TestPad`, `Hills`, `Real`), each
building a boxed `World`. The default on startup MUST be `TestPad` — flat ground gives clean
data for grip tuning.

#### Scenario: Player picks a map

- **WHEN** a `MapKind` is selected in the map picker
- **THEN** `MapKind::build()` returns the matching `World` and it replaces the `Terrain` resource

#### Scenario: Default startup terrain

- **WHEN** `Terrain::default()` is used
- **THEN** the active world is `FlatWorld` (flat at `GROUND_TOP`, normal `Vec3::Y`)

### Requirement: Real terrain from SRTM tiles

`HeightField::from_hgt` MUST read a square SRTM `.hgt` tile, detect SRTM1 (3601²,
spacing ≈ 30.87 m) or SRTM3 (1201², spacing ≈ 92.6 m) from the sample count, convert the
big-endian `i16` samples, and flip rows — SRTM rows run north→south while row 0 must be the
smallest Z. Between grid points height MUST be bilinearly interpolated, and queries outside
the grid MUST clamp to the edge instead of panicking.

#### Scenario: Malformed .hgt file

- **WHEN** the file has an odd byte count or a non-square sample count
- **THEN** `from_hgt` returns `Err` with a description instead of panicking

#### Scenario: Missing SRTM tile

- **WHEN** `real_terrain()` cannot load `assets/N50E014.hgt`
- **THEN** the error is reported on stderr and the fallback `HeightField::test_hill()` is used,
  so the game still starts

#### Scenario: SRTM void samples

- **WHEN** a sample equals `-32768` (SRTM void)
- **THEN** it is treated as 0 m

#### Scenario: Query outside the grid

- **WHEN** `height(x, z)` is called outside the tile
- **THEN** the coordinates are clamped into the grid and a valid edge height is returned

### Requirement: Render mesh is sampled from the same source

The terrain render mesh MUST be generated by sampling the same `World::height`/`normal`
(`terrain_mesh`), so what is drawn and what the car drives on cannot diverge. UVs MUST span
0..1 across the whole patch, with tiling handled by the material's `uv_transform`.

#### Scenario: Terrain mesh built for the active world

- **WHEN** `terrain_mesh(world, size, step)` is called
- **THEN** the vertex grid samples `world.height`/`world.normal` at each grid point
- **AND** two CCW triangles (seen from above) are emitted per cell

### Requirement: Rapier is limited to the static world

Rapier colliders MUST be used for static world geometry (ground) only. Vehicles MUST never
be simulated by rapier — they run entirely on the custom node-beam solver.

#### Scenario: Ground collider spawned

- **WHEN** the static ground is spawned
- **THEN** it is a rapier fixed body bundle from `src/physics.rs`
- **AND** `Collider::cuboid` is given HALF extents

#### Scenario: A change proposes a rapier body for a car

- **WHEN** a change would route any part of a vehicle through rapier
- **THEN** it violates an architecture invariant and MUST be rejected or explicitly
  re-decided in a proposal
